# 6. Props

Computers must look modern.

Do not use futuristic holographic computers.

Technology should visually integrate with the historical environment.

---

Every external asset must have a documented license.

Do not use:

copyright-infringing ripped game assets

Avatar assets

unlicensed movie assets
