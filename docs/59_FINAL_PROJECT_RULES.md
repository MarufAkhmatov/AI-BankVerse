# AI BankVerse — Final Project Rules

## RULE 01

This is not a retro game.

---

## RULE 02

This is not a traditional banking dashboard.

---

## RULE 03

This is not simply a chatbot.

---

## RULE 04

The primary experience is a living 3D virtual bank.

---

## RULE 05

AI employees must have physical human representations.

---

## RULE 06

AI employees must move naturally.

---

## RULE 07

Characters must support:

walking

running

sitting

standing

typing

listening

speaking

gesturing

facial animation

eye tracking

---

## RULE 08

Voice is a first-class interaction method.

---

## RULE 09

Users may explore manually.

---

## RULE 10

Users must also be able to complete services immediately through voice.

---

## RULE 11

"Go to the payment department" must NOT be mandatory for payment.

---

## RULE 12

The 3D environment is the interface.

---

## RULE 13

Contextual UI appears when required.

---

## RULE 14

AI does not directly control banking databases.

---

## RULE 15

All financial operations go through authorized banking tools.

---

## RULE 16

Financial operations require explicit confirmation when required.

---

## RULE 17

Backend determines transaction success.

---

## RULE 18

AI must never fabricate transaction success.

---

## RULE 19

Claude Code is the development assistant.

---

## RULE 20

The project does not require an Anthropic API key for Claude Code development.

---

## RULE 21

Claude Code authentication remains outside the repository.

---

## RULE 22

Runtime AI is provider-independent.

---

## RULE 23

MVP can run with MockAIProvider.

---

## RULE 24

MVP can run with MockBankingProvider.

---

## RULE 25

The first target is a vertical slice, not the complete bank.

---

## RULE 26

The first vertical slice must demonstrate:

3D BANK

+

PLAYER

+

RECEPTION AI

+

VOICE

+

PAYMENT AGENT

+

ELECTRICITY PAYMENT

+

CONFIRMATION

+

MOCK TRANSACTION

+

NPC

+

ANIMATION

---

## RULE 27

Modern visual quality is mandatory for final presentation.

Target:

2020s AAA 3D quality.

---

## RULE 28

Avatar: The Game is only a high-level visual reference.

No Avatar IP may be copied.

---

## RULE 29

No unnecessary combat mechanics.

---

## RULE 30

The final user reaction should be:

"I am inside a digital bank."

not:

"I am using a banking app."

---
