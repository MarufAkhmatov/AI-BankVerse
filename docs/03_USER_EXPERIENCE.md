# AI BankVerse — UX Specification

## 1. First Launch

Opening sequence:

1. Logo
2. Loading environment
3. Camera enters bank entrance
4. Door opens
5. Player enters
6. Reception AI notices player
7. Reception AI greets user

Example:

"Assalomu alaykum. AI BankVerse'ga xush kelibsiz. Sizga qanday yordam berishim mumkin?"

---

## 2. Reception

Reception is the central navigation intelligence.

Reception understands:

- banking intent
- service intent
- user context
- urgency
- previous conversation

Reception can:

- answer questions
- open service interfaces
- direct user to department
- summon AI specialist
- provide information
- start transaction

---

## 3. Voice First

Voice interaction is the primary interaction method.

User should be able to say:

"Kredit olmoqchiman."

"Hisobimdagi pulni ko'rsat."

"Elektr energiyasiga to'lov qil."

"Oxirgi tranzaksiyalarimni ko'rsat."

"Men uchun depozit variantlarini top."

---

## 4. Visual UI

Voice does not eliminate UI.

Instead:

VOICE
+
3D ENVIRONMENT
+
CONTEXTUAL UI

Example:

User says:

"Elektr to'lovi."

The system opens a floating contextual panel.

The panel contains:

Provider
Account
Outstanding balance
Amount
Confirm

---

## 5. Contextual UI

UI must appear only when needed.

Avoid permanent large menus.

The environment itself is the navigation system.

---

## 6. Department Navigation

Each department must have recognizable visual identity.

Credit:

- desks
- credit screens
- financial charts
- application counters

Deposit:

- savings visuals
- interest rate displays
- investment information

Payments:

- payment terminals
- utility providers
- transaction screens

---

## 7. Mobile Adaptation

The product may eventually run on mobile.

Mobile version must not attempt to render the entire AAA environment at maximum quality.

Architecture must support:

HIGH-END
MEDIUM
MOBILE

quality tiers.

---

## 8. Accessibility

Support:

- text alternative
- captions
- voice alternative
- large text
- high contrast
- reduced motion
- simplified navigation
