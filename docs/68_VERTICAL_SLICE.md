# AI BankVerse — Vertical Slice

## Goal

Prove the complete product concept in one playable environment.

---

# Environment

ONE monumental banking hall.

No second floor.

No mezzanine.

No upper level.

---

# Required Areas

Entrance

Reception

Payment

Credit

Deposit

Central customer area

---

# Required Characters

Player

Reception Agent

Payment Agent

Credit Agent

3–5 Customer NPCs

---

# Required Interaction

Player enters.

Reception greets.

Player speaks.

AI understands.

Payment Agent receives task.

Payment UI opens.

User confirms.

Mock transaction executes.

Receipt appears.

NPCs continue moving.

---

# Required Visual Quality

The vertical slice must already communicate:

- monumental architecture
- marble
- chandeliers
- realistic characters
- modern lighting
- high ceiling
- cinematic perspective

It must NOT look like a generic greybox
when presented as the demo.

---

# Completion Definition

A person seeing the prototype for the first time
must understand the concept without explanation.
