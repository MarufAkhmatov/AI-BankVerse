# AI BankVerse — Mobile Architecture

## 1. Product Strategy

The mobile version must preserve the concept
without requiring desktop-class rendering.

---

# 2. Mobile Modes

MODE A:

Immersive 3D

MODE B:

Fast Service

MODE C:

Voice First

---

# 3. Mobile Start

User opens application.

Instead of a traditional dashboard:

virtual bank environment loads.

---

# 4. Voice Shortcut

User says:

"Elektr to'lovini qil."

System immediately opens:

Electricity Payment

---

# 5. Touch

User can:

tap agent

tap department

tap service

swipe camera

move character

---

# 6. Performance

Mobile rendering must support scalable quality.

Target profiles:

High

Medium

Low

---

# 7. Geometry

Use:

LOD

Nanite where supported and appropriate

occlusion

culling

streaming

---

# 8. NPC

Mobile should use lower NPC density.

---

# 9. Voice

Voice remains primary.

---

# 10. UX Principle

Mobile must not become:

"desktop UI squeezed onto phone."

It remains:

"virtual bank adapted to mobile."
